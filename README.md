# ArduPilot Parameter Explorer

A static web app for searching, inspecting, comparing, and exporting default parameter configurations across ArduPilot vehicles (Copter, Plane, Rover, Tracker, Sub, Blimp) and firmware releases. Parameter and metadata definitions are fetched live from the ArduPilot GitHub repository and Autotest server; nothing is bundled or precomputed.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
